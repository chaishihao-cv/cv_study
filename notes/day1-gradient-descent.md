## 一、今天到底做了什么

用纯 numpy 手写梯度下降，让程序自己"猜"出一条直线 `y = w*x + b`：

- 给它 100 个带噪声的点（真值 `y = 2x + 3`）
- 参数 `w`、`b` 都从 0 开始，完全不知道答案
- 每轮：算预测值 → 算损失 → 求梯度 → 微调参数，重复 200 轮
- 结果：学出 `y = 2.021x + 2.969`，loss 从 **10.28** 降到 **0.0733**

**这就是所有深度学习训练的本质，只是参数从 2 个变成几百万个。**

---

## 二、训练循环的五步（核心，必须能默写）

```
预测 → 算损失 → 求梯度 → 更新参数 → (记录)
```

```python
w, b = 0.0, 0.0
for epoch in range(epochs):
    y_pred = w * x + b                        # 1 前向：用当前参数算预测
    loss = np.mean((y_pred - y) ** 2)         # 2 损失：MSE
    loss_history.append(loss)                 #    记录，供画曲线
    grad_w = np.mean(2 * (y_pred - y) * x)    # 3 梯度：对 w 求导
    grad_b = np.mean(2 * (y_pred - y))        # 3 梯度：对 b 求导
    w = w - lr * grad_w                       # 4 更新：沿负梯度走一步
    b = b - lr * grad_b
```

### 梯度公式怎么来的
对 `loss = mean((w*x + b - y)²)` 分别对 w、b 求偏导（链式法则）：

```
dLoss/dw = mean( 2*(y_pred - y)*x )
dLoss/db = mean( 2*(y_pred - y) )
```

自己手推一次，就知道代码里那两行不是玄学。

## 三、四个关键概念

### 1. 训练集 / 验证集 / 测试集

| 集合 | 类比 | 用途 | 使用频率 |
|---|---|---|---|
| 训练集 | 平时练习题 | 更新参数 | 反复用 |
| 验证集 | 模拟考 | 调超参（学习率、轮数）、早停、判断过拟合 | 反复用 |
| 测试集 | 高考 | 最终评估模型性能 | **只能用一次** |

**为什么必须划分**：模型会"记住"它见过的数据。验证集、测试集一旦参与过训练或调参，评估结果就不再客观。

### 2. 欠拟合 / 过拟合 / 泛化

- **欠拟合**：学得太浅，训练集都做不对 → 训练 loss 也高
- **过拟合**：死记硬背 → 训练 loss 极低，验证 loss 先降后升
- **泛化**：对没见过的数据表现好，这才是模型真正追求的目标

**判断口诀（看两条曲线）**
- 两条都高、贴在一起 → 欠拟合
- 训练降、验证拐头向上 → 过拟合
- 两条都低且贴合 → 良好

### 3. MSE 与交叉熵

| 损失 | 用于 | 直觉 |
|---|---|---|
| MSE | 回归（预测连续数值） | 平均平方误差，今天用的就是它 |
| 交叉熵 | 分类（预测概率分布） | 对"自信地答错"惩罚极重 |

> 今天只需知道分工；具体推导等 day4 训练 MNIST 时用上手。

### 4. 梯度下降

下山比喻：蒙着眼站在山坡，靠脚下的坡度判断方向。

- **梯度** = 坡度（损失对参数的变化率）
- **学习率 lr** = 每步迈多大
- 更新公式 `w = w - lr*grad`，**减号**来自"沿负梯度方向损失下降最快"

## 四、三组对照实验（真实数据 + 曲线形态）

| 实验 | 设置 | 实测结果 | 结论 |
|---|---|---|---|
| 对照 | lr=0.1, 200轮 | loss 10.28 → **0.0733**，w=2.021, b=2.969 | 步长合适，约 50 轮收敛 |
| 实验1 | lr=0.01, 200轮 | loss 停在 **0.168**，w=1.505, b=2.917 | 步长太小，**没走到底** |
| 实验1b | lr=0.01, 50轮 | loss 停在 **2.00** | 更明显，几乎没学到 |
| 实验2 | lr=1.5, 50轮 | loss 冲到 **2.8e30**，b=-3.34e15 | **发散/爆炸** |
| 实验3 | lr=0.1, 50轮 | loss **0.0747** | 轮数够，因为收敛快 |

### 1. 三种学习率的曲线形态（重要）

| lr | 曲线形状 | 参数表现 |
|---|---|---|
| 0.01 | 缓慢下降，200 轮**还没变平** | 红线斜率 1.50，明显小于真值 2.0，两端偏离大 |
| 0.1 | 前 30 轮陡降，之后**变平** | 红线几乎压住黑虚线 |
| 1.5 | 前面看着"平"，第 45 轮后**直冲 1e30** | b 变成 -334 万亿，红线跑到画布外 |

**判断收敛的三种形态**：还没变平 = 没收敛；变平 = 收敛；陡然上升 = 发散。

### 2. 发散的数学本质（今天最值钱的一课）

发散不是"某一步突然坏掉"，而是**每轮误差按固定倍数放大**。

这组数据里 `b` 的更新可近似看作：

```
b_new ≈ b_old × (-2)      # 每轮绝对值翻倍
```

于是：

- 10 轮后 ≈ 1024 倍
- 50 轮后 ≈ **1e15 倍**

实测 `b = -3342623485249895`，正好是 2^51 量级，和推算完全吻合。

> **结论：指数增长在线性坐标上看起来就是"一直很平，然后突然变成竖直的线"。**
> 看到 loss 变 `inf` / `NaN` / 1e20，第一反应：**学习率太大**。

### 陷阱 1：多个数量级必须用对数坐标
`lr=1.5` 的 loss 从 10 涨到 3e30，同一根线性坐标轴上，前面正常的 0.07~10 被压成一条贴地直线，**看起来像"一直没变化"**。

```python
axes[0].set_yscale("log")   # 加这一行，立刻能看到"先降后爆"的 V 形
```

### 陷阱 2：一个极端值把整张图压扁
右图 `b = -3.34e15`，matplotlib 自动把纵轴拉到 1e15 量级，结果数据点全挤成顶上一条细线，什么都看不见。

**习惯动作：画图前先看数值范围，超过三个数量级就换对数轴或手动 `set_ylim`。**

## 六、代码里几个容易卡住的点

| 位置 | 说明 |
|---|---|
| `loss_history.append(loss)` | 把每轮 loss 存进列表，最后画曲线用；`loss_history[0]` 是起始值，`[-1]` 是最终值 |
| `if epoch % 50 == 0 or epoch == epochs-1` | 每 50 轮打印一次；`or` 后半句保证**最后一轮（199）也被打印**；`%` 是取余 |
| `{loss:8.4f}` | 格式化：占 8 格宽、4 位小数，让数字纵向对齐便于比较 |
| `np.mean(...)` 不能省 | 漏掉就是求和没平均，梯度放大 100 倍，训练直接炸 |
| `w = w - lr*grad` | **减号**写错成加号，loss 会一路上升 |

### ⚠️ 亲测踩到的报错：`Invalid format specifier`

```python
print(f'... loss {loss:.4f } ...')     # ❌ ValueError: Invalid format specifier '.4f '
```

原因：**`f` 后面多了一个空格**。实测各种写法：

| 写法 | 结果 |
|---|---|
| `{loss:.4f}` | ✅ `0.0733` |
| `{loss:.4f }` | ❌ 报错（类型符 `f` 必须是最后一个字符） |
| `{w: 6.3f}` | ✅ 合法（冒号后第一个空格是"符号位"，正数前留白） |
| `{w:6.3f}` | ✅ 合法，效果同上 |

**记忆口诀**：冒号后的空格是符号位、合法；小数点和类型符之间不能有空格。

### ⚠️ 另一个坑（day4 起会踩）
用 PyTorch 时，记录 loss 必须写 `loss_history.append(loss.item())`。
直接 append Tensor 会把计算图挂在列表上，占显存，跑久了 `CUDA out of memory`。
