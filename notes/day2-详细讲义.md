# 第 2 课 · 激活函数与梯度消失

> 配套代码：`stage3_pytorch/day2_activation_plot.py`
> 前置：第 1 课（训练循环、梯度、学习率）
> 本课定位：解释"网络为什么能学会弯的东西"，以及"深网络为什么训不动"

---

## 0. 本课要解决的问题

第 1 课的模型是 `y = w*x + b`。它只能画直线。

如果你手上是弯曲的关系（比如"温度越高、销量先升后降"），这个模型永远拟合不了。**今天要解决的就是：怎么让模型有能力表达曲线。**

答案不是"换更复杂的公式"，而是在层与层之间插一个**非线性函数**。这个函数就叫激活函数。

---

## 1. 为什么必须有激活函数（这一节是数学必需，不是技巧）

### 1.1 先做一次代入

两层线性层：

```
第一层：h = w1*x + b1
第二层：y = w2*h + b2
```

把 h 代进第二层：

```
y = w2*(w1*x + b1) + b2
  = (w2*w1)*x + (w2*b1 + b2)
  = W*x + B
```

**结果还是一个一次函数。** 两个参数 `W = w2*w1`、`B = w2*b1+b2` 把两层"压扁"成了一层。

### 1.2 推广到 100 层

同理，100 层线性层叠起来，等价于 **1 层**，只是斜率是 100 个 w 的乘积、截距是它们的一个组合。

**所以：没有非线性，深度完全没意义。** 加层不会让模型更强，只是把参数做了个乘法。

### 1.3 加一个非线性会怎样

```
h = relu(w1*x + b1)     ← 中间插一个"掰弯"的函数
y = w2*h + b2
```

现在 `y = w2*relu(w1*x+b1) + b2` —— 它是一条**折线**（在 x 的某一点突然拐弯）。

两层就能拐一次弯；层数越多，能拐的弯越多；**足够多的折线段可以逼近任何连续曲线**。

> 这就是神经网络的表达能力来源：**不是参数多，而是"折点"多。**

---

## 2. sigmoid：最早的主力，也是梯度消失的源头

### 2.1 公式与形状

```
σ(x) = 1 / (1 + e^(-x))
```

- 值域 `(0, 1)`
- x=0 时输出 0.5
- x 很大 → 输出趋近 1；x 很小 → 趋近 0
- 形状是"S 形"，两头压平

它原本的用途是**把任意数压成概率**，所以历史上被广泛用来做隐藏层。

### 2.2 导数推导（这就是梯度消失的根源）

sigmoid 有一个非常漂亮的导数性质：**导数可以用输出本身算出来**。

```
σ'(x) = σ(x) * (1 - σ(x))
```

推导要点（记不住过程没关系，记住结论）：
- `σ(x)` 满足 `σ' = σ(1-σ)`，这是它被设计成指数形式带来的福利
- 好处：前向算出 `s = σ(x)` 后，反向直接用 `s*(1-s)`，不用重算

### 2.3 关键数字：导数最大只有 0.25

`s*(1-s)` 是个开口向下的抛物线，最大值在 `s=0.5` 时：

```
0.5 * (1 - 0.5) = 0.25
```

**sigmoid 的导数，任何位置都不会超过 0.25。**

而且在两头（x 很大或很小）时，`s` 接近 1 或 0，导数接近 **0**——这叫**饱和**。

**这个 0.25 就是整节课最重要的数字。** 后面所有"梯度消失"的推理，都从它出发。

---

## 3. tanh：sigmoid 的改进版

### 3.1 公式

```
tanh(x) = (e^x - e^(-x)) / (e^x + e^(-x))
```

- 值域 `(-1, 1)`
- 和 sigmoid 长得几乎一样，但**以 0 为中心**（sigmoid 是 0.5 为中心）

### 3.2 两者的关系

```
tanh(x) = 2*σ(2x) - 1
```

就是 sigmoid 拉伸 + 平移。所以它们的毛病也一样：**两头饱和**。

### 3.3 导数

```
tanh'(x) = 1 - tanh(x)²
```

最大值在 x=0：`1 - 0 = 1`。

**比 sigmoid 的 0.25 大了 4 倍。** 这是 tanh 唯一的优势——梯度衰减速度慢一些。

### 3.4 为什么"零中心"很重要

sigmoid 的输出永远是正数（0~1）。这意味着下一层的输入永远同号，导致更新方向容易"同向偏"，收敛走 Z 字形。

tanh 输出可正可负，均值接近 0，所以**收敛更快、更稳**。

> 工程结论：**同一时期，tanh 普遍优于 sigmoid**，就是因为它零中心 + 导数上限更大。

---

## 4. ReLU：让深层网络成为可能的那个函数

### 4.1 公式

```
ReLU(x) = max(0, x)
```

就这么简单：**负数变 0，正数不变。**

### 4.2 导数

```
x > 0 时：导数 = 1
x < 0 时：导数 = 0
x = 0 时：不可导（实际用 0 或 1 代替，不影响训练）
```

### 4.3 为什么它能治梯度消失

这是本课最核心的一段推理。

**sigmoid 的问题**：每层导数 ≤ 0.25，反向传播是连乘，10 层后：

```
0.25^10 ≈ 0.00000095     （约百万分之一）
```

第 1 层收到的梯度只有输出的百万分之一 → 几乎不动 → **深层网络训不动**。

**ReLU 的优点**：正区间导数恒等于 **1**。连乘 10 层：

```
1^10 = 1     （完全不衰减）
```

**梯度能原封不动地传回第一层。** 这就是 2012 年 AlexNet 能把网络做到 8 层、后来能做到 100+ 层的直接原因。

### 4.4 ReLU 的代价（必须知道的三个缺陷）

| 缺陷 | 说明 | 后果 |
|---|---|---|
| **死区（dead ReLU）** | x<0 时梯度为 0，参数再也不更新 | 神经元永久"死亡"，白占算力 |
| **不可导** | x=0 处导数不存在 | 理论瑕疵，实际无影响（用 0 或 1 近似） |
| **输出非零中心** | 输出永远 ≥0 | 收敛略慢（但仍优于 sigmoid） |

**死区的成因**：学习率过大（一步跨到全是负区）、初始化不当、或数据分布偏移。一旦某个神经元的输入长期为负，它的梯度永远是 0，**再也救不回来**。

### 4.5 折中方案：Leaky ReLU

```
LeakyReLU(x) = x      (x > 0)
             = 0.01x  (x < 0)
```

给负区一个很小的斜率（0.01），这样梯度不会完全归零，**死区问题大幅缓解**。

其他变体还有 ELU、PReLU、GELU（后者是 Transformer/ViT 的标配，day22 会遇到）。

## 5. 梯度消失：完整的数学链条

### 5.1 为什么会"消失"

反向传播的本质是**链式法则连乘**。假设网络有 L 层，每层导数记为 `d_i`：

```
传给第 1 层的梯度 ∝ d_L * d_(L-1) * ... * d_1
```

**连乘的特性**：只要每个因子都小于 1，层数一多，乘积趋近 0。

| 每层导数上限 | 10 层连乘 | 30 层连乘 |
|---|---|---|
| sigmoid: 0.25 | 9.5e-7 | 8.7e-19 |
| tanh: 1.0（实际常 0.5~0.8） | 1e-3 ~ 0.1 | 1e-9 ~ 0.001 |
| ReLU: 1.0 | **1.0** | **1.0** |

### 5.2 反过来也有问题：梯度爆炸

如果每层导数都略大于 1（比如 1.5），30 层就是 `1.5^30 ≈ 1.9e5`——梯度指数增长，训练直接炸飞（loss 变 NaN）。

**所以深层网络必须满足：每层梯度乘积 ≈ 1。** 这正是各种设计（ReLU、残差连接、BatchNorm、好的初始化）共同追求的目标。

### 5.3 梯度消失对训练到底有什么影响（本节回答"这跟我有什么关系"）

#### 5.3.1 先看它作用的那个语句

训练里真正改变参数的只有一句：

```
w = w - lr * grad_w
```

- `grad_w` 大 → 这一步改得多
- `grad_w` 接近 0 → **这一步几乎不改**

所以"梯度消失"的字面含义是：**前面几层的 `grad_w` 变成了接近 0 的数，它们在训练中几乎不动。**

#### 5.3.2 算一笔账：到底有多慢

假设第 1 层梯度是 `1e-7`（10 层 sigmoid 的典型量级），学习率 0.1：

| 量 | 数值 |
|---|---|
| 每步 w 的变化 | `0.1 × 1e-7 = 1e-8` |
| 1000 步累积 | `1e-5` |
| 权重本身量级 | 约 0.5 |
| 走完这个量级需要 | **约 5000 万步** |

而同一时刻，输出层拿到的梯度是 0.1 量级，每步走 0.01，**几百步就走完了**。

**结果：同一轮训练中，输出层飞速学，第 1 层原地不动。**

#### 5.3.3 五条具体后果

| 影响 | 具体表现 |
|---|---|
| **1. 深度被浪费** | 前几层等于停在随机初始化上，网络实际只有最后 2~3 层在学。堆了 20 层，真正起作用的可能只有 5 层 |
| **2. 学不到"低级特征"** | 图像任务里前层该学边缘、纹理，后层学"猫耳朵"。前层不学 → 后层只能拿随机特征凑，表达力差一截 |
| **3. 收敛极慢** | loss 会降，但需要几十万步。别人 1 万步收敛，你要 100 万步 |
| **4. 训练结果不稳定** | 前层固定在随机值上，换个随机种子结果就明显不同。同一份代码跑三次得到三个模型 |
| **5. 越深越失效** | 10 层勉强能用，30 层前 20 层等于冻结，loss 卡住不降，容易被误判成"模型太复杂" |

#### 5.3.4 实测：不是"完全不学"，而是"学习速度差几百倍"

5 层全连接、宽度 32、目标 `sin(x)`：

| | 第 1 层梯度 | 最后层梯度 | 差距 |
|---|---|---|---|
| sigmoid | 3.3e-04 | 1.8e-01 | **小 545 倍** |

注意：这个 sigmoid 网络最终 loss 只有 0.0017，**它确实学到了**。这恰好说明一个容易被误解的点：

> **梯度消失 ≠ 完全不学。它是"学习速度差 545 倍到 100 万倍"。**

层数少、目标简单时，慢一点也能学会；一旦到 10 层、30 层，差距变成百万倍，前层就彻底冻结。**杀伤力随深度指数增长。**

#### 5.3.5 为什么调大学习率救不回来

直觉上会想：前层梯度小，把 lr 调大 1000 倍不就行了？

问题是**同一个 lr 对所有层同时生效**：

| | 第 1 层梯度 | 最后层梯度 |
|---|---|---|
| 原梯度 | 1e-7 | 1e-1 |
| lr 放大 1000 倍后 | 走 1e-1 ✅ 终于动了 | **走 1e2 ❌ 直接炸** |

**前层刚被救活，输出层已经爆炸。** 这正是梯度消失最难缠的地方：**它是结构性问题，不是超参数问题**，只能从结构上解决：

- 换 ReLU（正区间导数恒为 1）
- 加 BatchNorm（把每层输入拉回正常尺度，day7）
- 加残差连接（`F(x)+x`，那个 `+1` 保证梯度至少原样传回，day12）

#### 5.3.6 一个类比：传话游戏

10 个人传话，规则是每人只能把听到的音量传 **1/4**：

```
第 1 人：100 分贝
第 2 人：25
第 3 人：6.3
...
第 10 人：0.0001 分贝   ← 完全听不见
```

反馈传回去时同理：最后一个人说"你该改改"，传到第 1 个人耳朵里已经听不见了。

**ReLU 的规则是"原样传"（乘 1），10 层传下来音量一点不变。** 这就是它解决了什么。

#### 5.3.7 怎么在自己的代码里识别

用 PyTorch 后，这行是标准诊断手段：

```python
for name, p in model.named_parameters():
    print(name, p.grad.norm().item())      # 看各层梯度大小
```

**如果第 1 层是 1e-6、最后一层是 1e-1，就是梯度消失了。** 这比看 loss 曲线直观得多，也是面试时能说出口的判断依据。

> 一句话总结本节：**梯度消失不会让模型报错，它悄悄让前几层停止学习——你仍在训练，但训练的是一个"假的浅网络"。**

### 5.4 残差连接（预告）

day12 会学 ResNet 的核心：

```
输出 = F(x) + x      ← 把输入直接加到输出上
```

导数是 `F'(x) + 1`，**那个 +1 保证梯度永远不会被乘没**。这是现代深网络能堆到 100 层以上的关键设计。

> 所以你在 day2 学的"梯度乘积要接近 1"这个直觉，是后面所有架构设计的底层逻辑。

## 6. 实战选择：什么时候用哪个

| 位置 | 用什么 | 原因 |
|---|---|---|
| **隐藏层**（中间层） | **ReLU / GELU** | 梯度不衰减，训练快 |
| 二分类输出 | sigmoid + 交叉熵 | 输出是 0~1 的概率 |
| 多分类输出 | softmax + 交叉熵 | 输出是各类概率，和为 1 |
| 回归输出 | **不加激活**（线性） | 预测的是任意实数 |

**新手最常犯的错**：在回归任务的输出层加了 sigmoid，导致预测值被压死在 0~1 之间，永远学不对。

## 7. 代码任务指引（`day2_activation_plot.py`）

### 7.1 四个函数怎么写

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def relu(x):
    return np.maximum(0, x)

def leaky_relu(x, alpha=0.01):
    return np.where(x > 0, x, alpha * x)
```

`tanh` 直接用 `np.tanh(x)`。

### 7.2 导数

```python
def dsigmoid(x):
    s = sigmoid(x)
    return s * (1 - s)      # 就是你推的 s*(1-s)

def dtanh(x):
    return 1 - np.tanh(x) ** 2

def drelu(x):
    return (x > 0).astype(float)     # 布尔转 0/1

def dleaky_relu(x, alpha=0.01):
    return np.where(x > 0, 1.0, alpha)
```

### 7.3 画图要点

- x 取 `np.linspace(-6, 6, 400)`：范围要够大，才能看到"饱和"那段变平
- 两列子图：左原函数、右导数
- **在右图上画一条 `y=0.25` 的水平虚线**，一眼就能看出"所有导数都在它下面"
- 加 `ax.grid(alpha=0.3)` 和 `ax.legend()`

### 7.4 跑起来之后要观察什么

| 观察 | 应该看到 |
|---|---|
| sigmoid 曲线 | 两头压平（饱和），中间陡 |
| sigmoid 导数 | 钟形，**峰值 0.25**，两头趋 0 |
| tanh 导数 | 钟形，**峰值 1.0**，比 sigmoid 高 4 倍 |
| ReLU 导数 | **阶跃**：负半轴 0，正半轴 1 |
| ReLU 原函数 | x<0 时是一条贴地的水平线 |

## 8. 常见误区

| 误区 | 事实 |
|---|---|
| "激活函数是玄学技巧" | 它是数学必需：没有它，深度毫无意义 |
| "层数越多越强" | 线性层叠多少层都等于 1 层；只有带非线性的深度才有意义 |
| "sigmoid 更好因为更平滑" | 它的导数上限 0.25 恰恰是深层网络的灾难 |
| "ReLU 简单所以粗糙" | 简单正是它的优势：导数恒为 1，计算也快 |
| "ReLU 一定比别的差" | 它治好了梯度消失，但引入了死区；所以才要 Leaky / GELU |
| "梯度消失 = 梯度太小所以加学习率" | 加学习率没用，问题在连乘结构，要改激活或加残差 |

## 10. 五句话总结本课

1. **没有激活函数，叠多少层都等于一层**（线性叠加仍是线性）
2. **sigmoid 导数上限 0.25**，反向连乘会把梯度衰减到百万分之一
3. **tanh 导数上限 1**，且零中心，全面优于 sigmoid
4. **ReLU 正区间导数恒为 1**，彻底解决衰减，但引入了"死区"
5. **深层网络的通用准则：让每层梯度乘积 ≈ 1**（后续的 BN、残差、初始化都在做这件事）
