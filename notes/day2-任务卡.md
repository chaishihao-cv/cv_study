## 任务2　理论（40 分钟）

### 2.1 必须先想清楚的问题

**如果两层都是 `y = w*x + b`，叠起来是什么？**

自己在纸上推：
```
第一层：h = w1*x + b1
第二层：y = w2*h + b2
代入后 y = w1*w2*x+(w2*b1+b2)
```

- [x] 推出结果，确认它仍然是"一条直线"（一次函数）
- [x] 得出结论：**没有非线性，叠 100 层也等价于 1 层**

### 2.2 三种激活函数的公式

| 函数 | 公式 | 值域 | 导数 | 导数最大值 |
|---|---|---|---|---|
| sigmoid | `1/(1+e^(-x))` | (0,1) | `s*(1-s)` | **0.25** |
| tanh | `(e^x-e^(-x))/(e^x+e^(-x))` | (-1,1) | `1-t²` | **1.0** |
| ReLU | `max(0,x)` | [0,+∞) | `x>0 ? 1 : 0` | **1.0** |
| Leaky ReLU | `max(0.01x, x)` | (-∞,+∞) | `x>0 ? 1 : 0.01` | 1.0 |

- [ ] 能说出 sigmoid 导数最大只有 0.25 意味着什么
- [ ] 能说出 tanh 为什么比 sigmoid 好一点
- [ ] 能说出 ReLU 在 x<0 时梯度是多少

### 2.3 梯度消失的算术

10 层 sigmoid 网络，每层梯度最多乘 0.25：

```
0.25^10 ≈ 0.00000095   （约百万分之一）
```

- [ ] 算出 `0.25^10` 的近似值（手算或计算器）
- [ ] 能解释"为什么深网络用 sigmoid 训不动前面几层"

## 任务4　实验一：梯度消失（60 分钟）

新建 `day2_gradient_vanish.py`。

**做法**：
1. 模拟 10 层"假网络"，每层只有一个 sigmoid
2. 从最后一层往回，把每层的梯度连乘起来
3. 打印每层梯度值，看它怎么一层层变小

**参考骨架**（自己补全）：
```python
grad = 1.0
for layer in range(10):
    grad = grad * 0.25      # 每层最多只能传 0.25
    print(layer, grad)
```
