## 三、答案区（对完再往下读，别提前看）

### day1

1. **预测 → 算损失 → 求梯度 → 更新参数 →（记录）**。第五步"记录"可省，前四步缺一不可。
2. `grad_w = np.mean(2 * (y_pred - y) * x)`，`grad_b = np.mean(2 * (y_pred - y))`。漏 `mean` = 只求和没平均，梯度**放大 100 倍**（本例样本数），训练直接炸。
3. 0.01 → **缓慢下降、200 轮还没变平**；0.1 → **前 30 轮陡降、之后变平**；1.5 → **前面看着平、第 45 轮后直冲**。实测 loss 冲到 **2.8e30**，`b ≈ -3.34e15`（约 2^51），本质是**每轮按约 -2 倍放大**。
4. **验证集可以反复用**（调超参、早停），**测试集只能用一次**，用过就不再客观。
5. **过拟合**（训练极低、验证很高）。

### day2

6. sigmoid **0.25**、tanh **1.0**、ReLU **1（正区）/ 0（负区）**、LeakyReLU **1 / 0.01**。
7. `0.25 ^ 10 = 9.537e-07`，约**百万分之一**。
8. `0.05 ^ 10 = 9.766e-14`，约**十四万亿分之一**；两者差 **约 100 万倍**。
9. **不是"完全不学"，而是"底层学得极慢"**——越靠近输入的层，学习速度越慢；实测不同尺度差 **545 倍到 100 万倍**。
10. **ReLU 死区**：输入恒为负时导数恒为 0，梯度永远传不回来，这个神经元的参数**再也不会更新**（永久失活）。缓解：LeakyReLU / 调小学习率 / 加 BatchNorm。

### day3

11. `requires_grad=True` = **声明这个量要参与求导**；`grad_fn` = **记录"我是怎么算出来的"**（计算图的指针）；叶子张量 = **用户自己创建、且不是由运算产生的张量**，梯度存在它的 `.grad` 里。
12. **从最右一维往左比，逐维判断：相等，或其中一个为 1，就兼容**。`(3,4)+(3,)` → 最后一维 4 对 3，既不相等也不是 1 → 报错。`(3,4)+(4,)` → 最后一维 4 对 4 通过，第二维 3 对"缺失"（视为 1）通过。
13. **反向传播时同一张量被多条路径用到，梯度是各路径相加**，所以框架不会自动清零。**`zero_grad()` 必须写在 `backward()` 之前**（写在之后等于白清）。
14. **把单元素张量取成 Python 数字**，同时脱离计算图。不用它直接 append 张量，会把计算图挂在列表上，**占显存、跑久 OOM**，打印也变丑。
15. 差 **1e-6 量级**：`w` 差 `0.00e+00`，`b` 差 `4.77e-07`。`b` 不是 0 是因为 **float32 只有约 7 位有效数字**，这个差值就是精度极限，不是算法错。

### day4

16. **① `__init__` 里定义层 ② `forward` 里定义前向计算 ③（把层赋成属性，参数自动注册）**。
17. softmax → `[0.659001, 0.242433, 0.098566]`，取 target=0 → `-ln(0.659001) = 0.41703`。**与框架实测完全一致**。
18. `zero_grad() → forward → loss → backward() → step()`，外面套 `model.train()` / `model.eval()`，循环里累加统计量。
19. 变成**跨轮累计平均**（历史所有批的总和 / 历史所有样本数）→ 打印会**虚高**。实测反推：显示 0.3465 / 0.2510 / 0.2032 / 0.1729 / 0.1513，真实本轮是 0.3465 / 0.1555 / 0.1076 / 0.0820 / 0.0649。
20. `len(train_loader) = 938`，末批 **32** 张（60000 % 64 = 32）。分母必须用 **`len(test_set)` = 10000**；写成 `len(test_loader)`（40）会算出 **24250%** 这种荒谬数字。

### day5

21. 输出 **3×3**，**9 个值全是 -6**。理由：左列和 18、右列和 24，`18 - 24 = -6`；窗口内上下三行完全一样，所以每个窗口都得 -6。
22. `out = (H + 2p - k) / s + 1`（整除）。`(224,7,3,2)` → `(224 + 6 - 7)/2 + 1 = **112**`。
23. `k=3, p=1, s=1` → **尺寸不变**（28→28）；`k=3, p=1, s=2` → **尺寸减半**（28→14）。
24. `params = k*k*Cin*Cout + Cout`。`3*3*3*64 + 64 = 1728 + 64 = **1792**`。**不是 576**——576 只是 `3*3*64`，漏了输入通道 3。
25. `MACs = H_out*W_out*Cout*(k*k*Cin) = 224*224*64*27 = **86,704,128**`；`FLOPs ≈ 173.4M`；复用次数 `86,704,128 / 1728 = **50,176 次**`。
26. 漏了 **`x = x.view(x.size(0), -1)`**（展平）。卷积输出是 `(64, 1568)` 的**四维张量**，`Linear(784,10)` 要的是 `(?, 784)`；1568 ≠ 784 而且维度数不对，所以报错。

