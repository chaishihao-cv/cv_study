## 二、四条激活函数（曲线形状必须记住）

| 函数 | 公式 | 值域 | 导数 | 导数最大值 |
|---|---|---|---|---|
| sigmoid | `s = 1 / (1 + exp(-x))` | (0, 1) | `s * (1 - s)` | **0.25** |
| tanh | `tanh(x) = 2*sigmoid(2x) - 1` | (-1, 1) | `1 - t^2` | **1.0** |
| ReLU | `max(0, x)` | [0, +∞) | x>0 → 1，x<0 → 0 | 1 |
| Leaky ReLU | `max(alpha*x, x)` | (-∞, +∞) | x>0 → 1，x<0 → alpha | 1 |

### 曲线上三个必须看到的特征

**1. 两条钟形导数曲线的高度差 4 倍**

sigmoid 导数封顶 0.25，tanh 导数封顶 1.0。**这就是 tanh 比 sigmoid 强的原因**，也是当年隐藏层从 sigmoid 换成 tanh 的直接动力。

**2. sigmoid 两头压平（饱和）**

`|x| > 4` 之后，曲线基本贴死在 0 或 1，导数贴死在 0。**神经元"饱和"了，就再也收不到梯度。**

**3. ReLU 在 x=0 处不可导**

导数从 0 直接跳到 1，画图只能画成一条竖线。实际训练里用 0 或 1 顶替，不影响结果。

## 三、梯度消失的机制（今天最核心的一节）

### 1. 反向传播就是一路连乘

前向传播时数据一层层往前算；反向传播时梯度一路往回传，**每穿过一层，就要乘上那一层的激活导数**：

```
dL/dw1 = dL/d_pred * f'1 * f'2 * f'3 * ... * f'10
```

如果每层导数都是 0.25：

```
0.25^10 = 9.537e-07
```

**关键：十次乘法，不是减十次。**

| 若是"每层损失一点"（线性） | 若是"每层乘一次"（指数） |
|---|---|
| `1 - 10*0.75 = -6.5` | `0.25^10 = 9.5e-07` |

**梯度消失是指数级衰减，所以它不是"小一点"，而是"几乎为零"。**

### 2. 逐层衰减实算表（10 层、出发梯度 = 1）

| 每层系数 | 第10层 | 第1层 | 衰减倍数 |
|---|---|---|---|
| sigmoid 理论上限 0.25 | 2.500e-01 | **9.537e-07** | 约 26 万倍 |
| sigmoid 远离 0 处 0.05 | 5.000e-02 | **9.766e-14** | 约 500 万亿倍 |
| tanh 实际 0.8 | 8.000e-01 | **1.074e-01** | 只掉 7.5 倍 |
| ReLU 正区间 1.0 | 1.000e+00 | **1.000e+00** | 完全不掉 |
| 假设 1.5（梯度爆炸） | 1.500e+00 | **5.767e+01** | 放大 57 倍 |

**同样 10 层，tanh 和 sigmoid 差了 100 万倍**——差距只来自"每层 0.8 还是 0.25"这 3.2 倍，10 层就是 `3.2^10 ≈ 1.1e5`。

> **0.25 是 sigmoid 的最好情况**（输入正好在 0 处）。网络里绝大多数神经元输入不在 0 附近，真实导数是 0.05 那一行。**所以真实网络比第 1 行惨得多。**

### 3. 层数一多就崩（每加一层掉两个数量级）

| 层数 | 结果 |
|---|---|
| `0.25^10` | 9.537e-07 |
| `0.25^20` | 9.095e-13 |
| `0.25^30` | 8.674e-19 |
| `0.25^50` | 7.889e-31 |

**20 层就掉到万亿分之一。** 这就是为什么纯 sigmoid 堆的深层网络根本训不动。

## 四、梯度消失对训练到底有什么影响

### 1. 第一笔账：最底层要走多少步

第 1 层拿到的梯度 9.5e-07，lr = 0.1，每步只移动：

```
9.5e-07 * 0.1 = 9.5e-08
```

让 w 从 0 走到 0.5 需要：

```
0.5 / 9.5e-08 ≈ 5.3e6 步   （五百多万步）
```

而同一时刻输出层的梯度是 0.25，每步走 0.025，20 步就到了。

**"梯度消失"的真实含义是：输出层 20 步收敛，最底层 500 万步。训练停在第 1000 轮时，后面几层已经学完了，前面几层几乎没动。**

### 2. 五个具体后果

| 后果 | 说明 |
|---|---|
| **学习速度极不平衡** | 后面的层学完，前面的层还在原地 |
| **学到的特征质量差** | 最前面的层负责最基础的纹理/边缘，它没学好，后面全是空转 |
| **训练"看起来收敛了"其实是假的** | loss 平稳了但远没到最优，早停会停错地方 |
| **调 lr 救不回来** | lr 调大，输出层先炸；调小，底层更不动。**这不是 lr 的问题** |
| **多堆层数反而更差** | 加层不涨性能甚至下降，和"理论上越深越强"矛盾 |

### 3. 为什么调学习率救不回来

梯度消失是**方向性**的问题（越往前越小），而 lr 是**全局统一**的倍数：

- lr 调大 1000 倍：底层终于动了一点，但输出层梯度从 0.25 变成 250，直接爆炸
- lr 调小：输出层动得更慢，整体训练变慢

**一个全局参数没法同时照顾"梯度差 545 倍"的两端。**

### 4. 实测对比（5 层、宽 32、目标 sin(x)）

| 激活 | lr | 初始梯度 L1 | 初始梯度 L6 | L1/L6 | 最终 loss | 第1层权重移动 |
|---|---|---|---|---|---|---|
| sigmoid | 0.05 | **3.3e-04** | 1.8e-01 | **小 545 倍** | 0.0017 | 0.0810 |
| ReLU | 0.002 | 1.5e-01 | 6.1e+00 | 小 41 倍 | 0.0126 | 0.0018 |

**两组都学出来了（loss 都很低），但 sigmoid 的第 1 层梯度比输出层小 545 倍。**

> **所以结论要说准：梯度消失 ≠ 完全不学，而是"学习速度差 545 倍到 100 万倍"。**

### 5. 两种"不降"要分清（我自己答错过）

| 现象 | 原因 | loss 表现 |
|---|---|---|
| **梯度消失** | 前面几层几乎不动 | **能降**，但降得越来越慢，最后停在次优水平 |
| **梯度为 0（死区）** | 前面几层完全不动 | 真的一点都不降 |

**判据：梯度消失是"降不到位"，梯度为 0 才是"完全不降"。**

### 6. 怎么诊断自己是不是遇到了

```python
for name, p in model.named_parameters():
    if p.grad is not None:
        print(f"{name:20s} grad.norm = {p.grad.norm().item():.3e}")
```

**看数量级：如果最后一层 1e-1、第一层 1e-7，差 6 个数量级，就是梯度消失。**

## 五、梯度爆炸（同一枚硬币的另一面）

每层系数大于 1 时，连乘变成放大：

```
1.5^10 = 57.665
1.5^50 ≈ 6.4e8
```

**症状**：loss 突然变成 `inf` 或 `NaN`，参数变成 1e15 量级，曲线前段平、后段直冲（和 day1 lr=1.5 发散长得一模一样）。

**对策**（后面会学）：
- 梯度裁剪 `torch.nn.utils.clip_grad_norm_`
- 权重初始化（Xavier / Kaiming）
- Batch Normalization
- 残差连接

## 六、ReLU 死区（任务5，待补）

**机制**：ReLU 在 x<0 时导数恒为 0。如果某个神经元的输入长期落在负数区间，它的梯度永远是 0 → 参数再也不更新 → **永久失活**，这就是"死区"。

**和梯度消失的区别**：

- 梯度消失：梯度很小但**不是 0**，还有救
- ReLU 死区：梯度**就是 0**，这个神经元彻底废了

**Leaky ReLU 的 `alpha=0.01` 就是解药**：负区间给一条 0.01 的缓坡，梯度不是 0，永远有流过去的可能。

## 七、为什么 ResNet 能解决这个问题

按上面逻辑，10 层网络梯度要乘 10 次导数，怎么调都衰减。ResNet 的做法是：

```
y = F(x) + x
```

**在计算时加了一条"直通车道" x。** 梯度回传时，可以沿 1 这条路径直接穿过去，不经过任何导数连乘。

```
dy/dx = F'(x) + 1
```

**因为有个 +1，梯度至少有 1 可以汇合，不会衰减到 0。** 这是 day2 的前瞻，day17 会真正用上。

## 八、画图（matplotlib 入门，今天第一次系统练）

### 1. 三层结构

```
Figure（整张画布）
  └── Axes（子图，可以有多个）
        ├── 曲线 / 散点 / 图片
        └── 标题、轴标签、图例、网格
```

```python
fig, axes = plt.subplots(1, 2)   # 1 张画布 2 个子图
axes[0].plot(x, y)               # 往子图 0 里画
axes[1].plot(x, y2)              # 往子图 1 里画
plt.show()
```

**记忆关键**：`axes[i].` = 往第 i 个子图放东西，`plt.` = 整张画布的操作。这两个搞混是最常见的错误。

### 2. 只需记住 10 个动作

| 动作 | 代码 |
|---|---|
| 折线 | `ax.plot(x, y, label=..., color=...)` |
| 散点 | `ax.scatter(x, y, s=8, alpha=0.6)` |
| 水平线 | `ax.axhline(y=0.25, linestyle="--")` |
| 垂直线 | `ax.axvline(x=0, color="gray")` |
| 标题 | `ax.set_title("Loss curve")` |
| 轴标签 | `ax.set_xlabel("epoch")` |
| 网格 | `ax.grid(alpha=0.3)` |
| 图例 | `ax.legend()`（**有 label 才显示**） |
| 限范围 | `ax.set_xlim(-6,6)` / `set_ylim(-0.2,1.2)` |
| 显示/保存 | `plt.show()` / `plt.savefig(...)` |

| 图里中文变方块 | 字体缺字形 → 标题/label **一律用英文** |
